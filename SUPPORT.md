# Support

Use this guide when you need help with `k8s-recovery-visualizer`.

## Before Opening An Issue

Please check:

- [README.md](README.md)
- [docs/README.md](docs/README.md)
- [docs/CLI.md](docs/CLI.md)
- [docs/GUI.md](docs/GUI.md)
- [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md)
- [docs/RBAC.md](docs/RBAC.md)

## Open A GitHub Issue When

- the CLI or desktop app behaves incorrectly
- a report or export artifact is wrong or missing
- documentation is stale or contradictory
- a release asset, installer, checksum, or workflow appears broken

Please include:

- the version or tag you used
- whether you used the CLI, desktop app, or both
- the commands or workflow you ran
- logs, screenshots, or redacted output bundles when safe to share

## Feature Requests

Open a feature request when you want new product capability, broader backup-tool coverage, packaging improvements, or documentation enhancements.

Please explain:

- the problem you are trying to solve
- who would benefit
- whether the request affects the CLI, GUI, reports, or release pipeline

## Security Issues

Do not report vulnerabilities in public issues.

Use [SECURITY.md](SECURITY.md) for private disclosure guidance.
