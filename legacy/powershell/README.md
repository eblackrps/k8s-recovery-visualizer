# Legacy PowerShell Pipeline

This directory contains the original PowerShell-based implementation that predated the current Go CLI.

Status:

- Archived for reference and historical comparison
- Not covered by the current GitHub Actions workflows
- Not included in the current release process
- Not the supported execution path for new work

The supported implementation lives in [`../../cmd/scan`](../../cmd/scan) and is the path used by current documentation, CI, schemas, and releases.

If you inspect or reuse these scripts, treat them as legacy code rather than the source of truth for current behavior.
